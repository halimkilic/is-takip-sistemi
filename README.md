# is-takip-sistemi

Bu iki eklenti, WordPress yönetim panelini kullanarak basit bir iş takip sistemi oluşturmaktadır. İşveren (admin) ve işçi (author) rollerinde kullanılır. İşveren iş oluşturur, işçiye atar ve işçi işi tamamlayıp form doldurup imza alır.

DİKKAT! : Klasör içerisinde 2 adet php dosyası yer almaktadır. Her ikisinide ayrı ayrı .zip yaparak admin > eklentiler > yeni ekle alanından ekleme yapmanız gerekmektedir.
